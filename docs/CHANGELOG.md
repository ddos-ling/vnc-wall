# 更新日志

本文件记录 VNC 电视墙的所有版本变更,最新版本在最上方。

## 🌈 0.1.1 `2026-10-24`

### 🐞 修复

- `界面`:远程光标绘制位置多叠加了一次画面偏移量,导致光标显示在真实鼠标点的下方/右方(画面带黑边时最明显),操作时表现为"点了没反应、点偏了"。现已改为严格跟随鼠标位置
- `界面`:设备掉线/断开后的提示不醒目。改为整条状态色顶栏 + 3px 粗边框 + 中央大字 + 重连倒计时,离线、已断开、密码错误、连接中四态一眼可辨

### 🔧 变更

- `界面`:鼠标坐标换算改以帧缓冲尺寸为准,不再依赖 `QImage` 实例,避免分辨率切换瞬间取到旧尺寸

## 🌈 0.1.0 `2026-10-24`

### ✨ 新增

- `协议`:自研 `RFB 3.8` 客户端,支持 `VNC Auth` 与 `None` 认证,兼容 `3.3 / 3.7 / 3.8` 三个协议版本
- `协议`:实现 `Raw`、`CopyRect`、`Hextile`、`ZRLE` 四种矩形编码解码,支持 `DesktopSize` 动态分辨率与 `Cursor` 光标伪编码
- `协议`:纯 Python `DES` 实现(含 VNC 密钥位序反转约定),无第三方加密库依赖
- `电视墙`:1×1 至 8×8 等分布局,支持自定义行列,格数变化时保留已填地址
- `电视墙`:多套方案管理,可新建、重命名、复制、删除,下拉切换时自动重连
- `设备`:按格位配置地址与密码,支持 `地址 密码` 批量粘贴导入
- `密码`:勾选记住后用 Windows `DPAPI` 加密存储,密文绑定当前用户,换机器无法解密
- `状态`:在线/连接中/离线/密码错误四态角标,离线显示红色边框、重连次数与倒计时
- `重连`:链路中断按 1/2/3/5/8/10 秒退避自动重连,认证失败不重试以免锁号
- `心跳`:5 秒静默后发 1×1 非增量探针,14 秒无响应判定离线,避免画面静止被误判为掉线
- `操作`:鼠标移动/点击/滚轮/拖拽与完整键盘转发,含 F1-F35、方向键、修饰键、Unicode 字符
- `操作`:右键菜单提供发送 `Ctrl+Alt+Del`、粘贴本机剪贴板、重新连接、断开、设置
- `界面`:双击画面进入单屏,`Esc` 返回,`F11` 全屏
- `界面`:单一帧定时器驱动全部格子,隐藏格不刷新;在线时地址标签收为左上小胶囊,减少遮挡
- `性能`:统一 32bpp 像素格式,帧缓冲直接映射 `QImage`,按脏矩形增量拷贝,静止画面几乎不占 CPU
- `自检`:内置最小 `RFB` 服务端,覆盖握手、认证、四种编码解码与键鼠上行;含 `ZRLE` 解码器单测

### 🔧 变更

- `协议`:默认只向服务端声明 `Hextile`/`Raw`,不声明 `ZRLE`——实测目标服务端的 `ZRLE` 数据缺少 tile 子编码字节,无法按规范解析,`Hextile` 在局域网下同样高效且更稳定
