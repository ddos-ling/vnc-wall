# VNC 电视墙

多路 VNC 画面集中显示 + 远程操作。纯 Python 实现 RFB 3.8 协议,不依赖任何 VNC 客户端库或外部二进制。

## 功能

- **自定义布局**:1×1 到 8×8 等分网格,一键切换或自定义行列
- **多套方案**:不同场景(机房/展厅/车间)各存一套布局+地址,下拉切换
- **密码登录**:支持 VNC 认证,勾选"记住"后用 Windows DPAPI 加密落盘(绑定当前账户,换机器无法解密)
- **远程操作**:鼠标点击/滚轮/拖拽 + 完整键盘(含 F1-F12、方向键、组合键),支持 Ctrl+Alt+Del 与粘贴本机剪贴板
- **掉线重连**:链路断开自动按 1/2/3/5/8/10 秒退避重连,界面上用红色边框 + "离线"标注,并显示重连倒计时
- **单屏模式**:双击任意画面放大,`Esc` 返回;`F11` 全屏

## 环境要求

- Windows 10/11,Python 3.12+
- `PySide6 >= 6.6`、`numpy >= 1.24`

```bat
pip install -r requirements.txt -i https://pypi.mirrors.ustc.edu.cn/simple
```

## 运行

```bat
python3 main.py
```

或双击 `run.bat`。

## 使用

1. 工具栏「布局」选行列数,当前布局有几格就能配几台设备
2. 「设备配置」逐行填地址和密码;也可以点「批量导入」按 `地址 密码` 一行一台粘贴
3. 地址格式 `192.168.1.1:5900`,端口省略时默认 5900
4. 保存后自动连接,状态栏显示「在线 n/m」

**快捷键**:`F11` 全屏 / `Esc` 退出单屏或全屏 / 双击画面进入单屏

**右键菜单**:重新连接、断开、单屏、发送 Ctrl+Alt+Del、粘贴本机剪贴板、设置此格

## 文件位置

| 内容 | 路径 |
| --- | --- |
| 配置 | `%APPDATA%\VncWall\config.json` |
| 日志 | `%APPDATA%\VncWall\logs\vnccwall.log` |

配置里的密码字段是 DPAPI 密文,形如 `dpapi:AQAAANCM...`。删掉配置文件即可恢复默认布局。

## 实现说明

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 协议 | `app/rfb/client.py` | 连接、握手、认证、消息循环、心跳、断线重连 |
| 协议 | `app/rfb/codec.py` | Raw / CopyRect / Hextile / ZRLE 解码,光标合成 |
| 协议 | `app/rfb/des.py` | 纯 Python DES,用于 VNC 认证 |
| 界面 | `app/ui/tile.py` | 单格显示、状态角标、键鼠转发 |
| 界面 | `app/ui/wall.py` | 主窗口、网格、方案、单屏 |

几个关键取舍:

- **强制 32bpp / depth 24 像素格式**,解码统一成 `B,G,R,X` 内存布局,直接喂给 `QImage`,无逐像素转换
- **帧数据零拷贝**:解码写 numpy 帧缓冲,UI 只把脏矩形拷进自己的缓冲,静止画面 CPU 占用接近 0
- **心跳探针**:画面静止时服务端不会发包,每 5 秒发一个 1×1 非增量请求,以此区分"没变化"和"链路死了",14 秒无响应才判定离线
- **认证失败不重试**,避免把对面账号锁死
- **编码选择 Hextile**:实测目标服务端(Xvnc)的 ZRLE 数据不写 tile 子编码字节,无法按 RFC 解析,故默认只声明 Hextile/Raw。ZRLE 解码器仍保留在 `codec.py` 并有单测覆盖,换服务端时可随时启用

## 已知限制

- 中文输入法无法直接进远端,用右键「粘贴本机剪贴板」代替
- 双击进入/退出单屏时,远端会收到一次单击(双击事件不转发,但按下-抬起已发生)
- 只支持 VNC 认证(None / VNC Auth)。服务端若强制 TLS(RealVNC 加密模式)、VeNCrypt 或 MSLogon,会提示"服务器要求不支持的认证方式"
- 客户端光标由服务端 Cursor 伪编码合成,若服务端不发送光标形状,则使用本机默认箭头

## 自检

python3 tests\protocol_check.py
